# توثيق مشروع الموقع الشخصي

## نظرة عامة
هذا المشروع عبارة عن موقع شخصي احترافي منظم وفق نمط MVC مع لوحة تحكم لإدارة المحتوى وقاعدة بيانات MySQL. يمكن تشغيل المشروع محلياً باستخدام XAMPP أو أي بيئة PHP مشابهة، ويدعم الثيم الفاتح/الداكن بالإضافة إلى تعدد اللغات (العربية والإنجليزية).

## المتطلبات المسبقة
- XAMPP أو خادم PHP + MySQL بديل
- PHP 8.0 أو أحدث
- Composer (اختياري في حال إضافة مكتبات مستقبلية)

## هيكلة المجلدات
```
project-root/
├─ public/            # ملفات الدخول العامة (index.php, admin-handler.php)
├─ app/
│  ├─ Controllers/    # المتحكمات للواجهة الأمامية ولوحة التحكم
│  ├─ Models/         # النماذج المسؤولة عن الاتصال بقاعدة البيانات
│  └─ Views/          # القوالب المخصصة للعرض
├─ assets/
│  ├─ css/            # ملفات الأنماط المشتركة (main.css, admin.css)
│  └─ js/             # ملفات جافاسكريبت (main.js)
├─ config/            # إعدادات الاتصال وقاعدة البيانات (config.php, database.php, schema.sql)
├─ storage/           # حفظ الملفات المرفوعة مستقبلاً
├─ admin.php          # نقطة الدخول للوحة التحكم
└─ docs/README.md     # هذا الملف التوثيقي
```

## خطوات الإعداد
1. **نسخ المشروع** إلى مجلد `htdocs` داخل XAMPP.
2. **إنشاء قاعدة البيانات**:
   - افتح phpMyAdmin أو سطر أوامر MySQL.
   - نفّذ محتويات الملف `config/schema.sql` لإنشاء الجداول والبيانات الأولية.
3. **تحديث بيانات الاتصال**:
   - افتح الملف `config/config.php` وعدّل بيانات الاتصال بقاعدة البيانات إذا لزم الأمر.
4. **تهيئة صلاحيات الرفع** (اختياري):
   - اجعل مجلد `storage/` قابلاً للكتابة إذا تم تمكين رفع الملفات لاحقاً.

## كيفية التشغيل
- افتح المتصفح وانتقل إلى `http://localhost/portfolio/public/index.php` للواجهة العامة.
- افتح `http://localhost/portfolio/admin.php` للوصول إلى لوحة التحكم.
- استخدم أزرار التبديل ضمن الواجهة لتغيير اللغة أو الثيم.

## بنية الكود
- **Controllers**: تجمع البيانات من النماذج وتنقلها إلى القوالب (`HomeController`, `AdminController`).
- **Models**: تتعامل مع جداول قاعدة البيانات عبر PDO (`UserModel`, `SkillModel`, ... إلخ).
- **Views**: تعرض البيانات وتدعم التخصيص البصري (`app/Views/home.php`, `app/Views/admin.php`).
- **Assets**: تحتوي على التصميمات والمؤثرات البصرية (CSS/JS).

## تخصيص المحتوى
- يمكن تعديل النصوص والمهارات والمشاريع من خلال لوحة التحكم دون تعديل الكود.
- يدعم المشروع رفع الصور عبر حفظ المسارات في قاعدة البيانات، ويمكن تطوير ميزة الرفع الفعلي بتوجيه الملفات إلى مجلد `storage/`.

## الأمن والتحسينات المقترحة
- إضافة نظام تسجيل دخول للوحة التحكم.
- تفعيل التحقق من صحة البيانات في `admin-handler.php` بشكل أعمق.
- استبدال نموذج الاتصال بإرسال بريد إلكتروني فعلي باستخدام PHPMailer.
- استخدام Composer لإدارة الاعتمادات المستقبلية إذا دعت الحاجة.

## الاختبارات والتشغيل
- تم تصميم الأنماط لتكون متجاوبة على الأجهزة المحمولة والحواسيب.
- يدعم الموقع تأثيرات التمرير السلس والتحريك عند ظهور العناصر.

للاستفسارات أو التوسعة، يمكن التعديل على الملفات وفق الهيكل الموضح أعلاه.
